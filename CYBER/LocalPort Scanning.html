5. Security Risk Analysis

  1. Port 80 (HTTP)
    • Data transmitted without encryption.
    • Vulnerable to packet sniffing and Man-in-the-Middle attacks.
  2. Port 445 (SMB)
    • Frequently targeted by ransomware and worms.
    • Should be restricted to trusted networks.
  3. Port 139 (NetBIOS)
    • Can reveal shared resources and system information.
    • Often disabled in modern secure environments.
  4. Port 135 (MSRPC)
    • May expose Windows services to remote enumeration.
    • Should not be exposed to untrusted networks.
  5. Port 53 (DNS)
    • If misconfigured, can be used for DNS amplification attacks.
  6. Port 7070
    • Verify whether this service is required.
    • Unnecessary services increase attack surface.

Conclusion

A TCP SYN scan was performed on the subnet 192.168.1.0/24 using Nmap. Four active hosts were identified. Open services including DNS, HTTP, HTTPS, MSRPC, NetBIOS, SMB, WSDAPI, and RealServer were discovered. Wireshark packet analysis confirmed SYN packets, SYN-ACK responses from open ports, and RST responses from closed ports. The scan results provide an overview of exposed services and potential security risks that should be reviewed and mitigated where necessary.
